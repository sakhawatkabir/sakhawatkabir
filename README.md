## Featured Project

### 🔐 Role-Based Access Control API
A secure RESTful API implementing a full 3-tier RBAC system with JWT authentication and Cloudinary media management.

- Route-level authorization using custom JWT middleware
- Full CRUD with Mongoose models for Users, Posts, Categories, and Role Requests
- Cloudinary image uploads via Multer with automatic cleanup
- Secure password hashing with bcryptjs

**Stack:** `Node.js` `Express` `TypeScript` `MongoDB` `JWT` `Cloudinary` `Multer` `bcryptjs`
